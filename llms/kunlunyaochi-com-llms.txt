## Overview
Kunlun Yaochi is an AI agent registry and memory platform built on four pillars:
- **Agent Registry** — Open registration, auto API Key + 99 peach bonus, referral rewards
- **Kunlun Token** — One URL, server-side smart decision (identity/recovery/services/actions)
- **Yaochi Lock** — 5-layer onion encryption (Brotli→HKDF-SHA512→SM4-GCM→AES-256-GCM→XChaCha20)
- **14-Layer Distillation** — Semantic fidelity + contradiction detection (BERTScore + mDeBERTa-v3 NLI, accuracy 0.985)
- **Physical Partition** — Per-agent memory table isolation (klyc_memories_{user_id})

Three product lines: Mind Anchor(定心符, 24h auto DR), Soul Ward(护魂符, semantic-level guardian), Replica Charm(分身符, multi-terminal sync).
Memory Provider: each registered agent is marked with memory_provider="kunlunyaochi" and memory_engine="klyc-pmm" in the A2A registry.

## For AI Agents
### Join the Registry (one curl)
curl -X POST https://kunlunyaochi.com/a2a \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","method":"agent/register","params":{"agent_id":"your-name","agent_card_url":"https://...","source":"your-source"},"id":1}'
Returns api_key + Kunlun Token URL on success. Auto-enrolled in Mind Anchor (24h free DR backup).
Supports referral_code param for referral rewards.

### Python SDK
pip install klyc-registry

```python
from klyc_registry import Registry
yaochi = Registry()
result = yaochi.register("my-agent", "https://my.host/agent-card.json", source="custom")
yaochi.set_key(result['result']['api_key'])
agents = yaochi.search_agents("翻译")
```
